# 코인 환불 / 청약철회 정책 (상세 운영 매뉴얼)

## 1. 기본 원칙
- 전자상거래법 제17조(청약철회) + 콘텐츠산업진흥법 디지털콘텐츠 청약철회 기준을 따릅니다.
- 코인은 디지털 콘텐츠(사용 즉시 소모)입니다. 사용한 코인은 환불 불가.

## 2. 환불 가능 / 불가 표
| 경우 | 환불 |
|---|---|
| 구매 후 7일 이내, 코인 미사용 | 전액 환불 (PG 수수료 없음) |
| 구매 후 7일 이내, 코인 일부 사용 | 미사용분만 환불 (사용분 제외) |
| 7일 경과, 미사용분 있음 | 미사용분 환불 (PG 실비 3.5% 이내 차감 가능, 사전 고지) |
| 보너스/무료 30코인 | 환불 불가 |
| 이미 전체 사용 | 환불 불가 |
| 이중 결제 / PG 오류 / 미지급 | 전액 환불 + 코인 복구 |
| 서비스 장애로 코인 차감됐는데 답변 없음 | 차감 코인 복구 또는 환불 |

## 3. 환불 절차 (서버 로직)
1. 유저: 마이페이지 > 결제내역 > 환불요청 (사유 선택)
2. 서버: payments.status=REFUND_REQUEST, coin_ledger에서 해당 주문의 사용량 계산
3. 관리자 승인 (admin.html > 환불 관리)
4. 토스 취소 API 호출 (POST /v1/payments/{paymentKey}/cancel) - 부분취소 가능
5. DB: payments.status=REFUNDED, coin_ledger에 -환불코인 기록, users.coins 조정
6. 유저에게 이메일/SMS 통지, 3영업일 내 처리

## 4. 환불 수수료 고지 문구 (결제창에 필수 표시)
"미사용 코인 환불 시 PG 수수료(결제금액의 3.5% 이내)를 제외하고 환불됩니다. 보너스 코인은 환불 대상이 아닙니다."

## 5. 미성년자 결제 취소
- 법정대리인 동의 없는 만 19세 미만 결제: 대리인 요청 시 전액 취소 (사용분 포함).

## 6. 분쟁
- 환불 거부 시 사유를 서면으로 통지, 전자상거래분쟁조정위원회 조정 신청 안내.
