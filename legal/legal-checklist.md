# 법적 체크리스트 - 운영 전 필수 (이거 안 하면 과태료/영업정지 가능)

## 1. 사업자 / 통신판매
- [ ] 사업자등록 (업종: 정보통신업/전자상거래 등)
- [ ] 통신판매업 신고 (관할 시군구청) - 신고번호를 푸터+약관에 표시
- [ ] 사업자 정보: 상호/대표/주소/전화/이메일/사업자번호/통신판매번호/호스팅사 - 푸터에 전부 표시 (전자상거래법 제13조)
- [ ] 대표자 실명 + 연락처 공개

## 2. 결제 / PG
- [ ] 토스페이먼츠 가맹점 가입 + 사업자 정보 제출 + 심사
- [ ] 테스트키 -> 라이브키 전환 (라이브키를 프론트에 노출 금지, 시크릿키는 서버 .env에만)
- [ ] PG 이용약관 동의, 에스크로/구매안전서비스 고지 (해당 시)
- [ ] 현금영수증 발행 안내 (계좌이체/휴대폰 결제 시)
- [ ] 부가가치세: 코인 충전은 선불전자지급수단? - 세무사 확인 필요. 영수증/세금계산서 발행 방식 확정
- [ ] 선불전자지급수단 발행 시 전자금융거래법 등록 여부 확인 (코인 규모 커지면 변호사/세무사 상담 필수)

## 3. 개인정보 / 보안
- [ ] 개인정보처리방침 게시 + 동의 체크박스 (필수/선택 구분)
- [ ] 개인정보 보호책임자 지정 + 연락처 공개
- [ ] 만 14세 미만 가입 차단 로직 (생년월일 검증)
- [ ] 비밀번호 해시, 개인정보 암호화, 접근 로그
- [ ] 개인정보 유출 대응 매뉴얼 + 신고 절차
- [ ] 쿠키 배너 (필수/선택)

## 4. 소비자 보호
- [ ] 이용약관 + 환불정책 게시 + 결제 전 동의 체크
- [ ] 결제 전 최종 확인 화면: 상품명/금액/코인/환불조건/유효기간 표시
- [ ] 청약철회 안내 + 환불 요청 버튼 (마이페이지)
- [ ] 고객센터 (전화/이메일) + 운영시간 표시, 3영업일 내 답변
- [ ] 표시·광고: "운세는 엔터테인먼트/참고용, 결과 보장 아님" 문구 모든 결과 화면에 표시 (과대광고 방지)
- [ ] 후기/별점 조작 금지 - 실제 후기만 표시, 구매자 후기임을 표시

## 5. 청소년 / 유해 콘텐츠
- [ ] 만 19세 미만: 연애/결혼/성 관련 상담에 대한 연령별 필터, 선정적 표현 차단
- [ ] 도박/투자 권유 표현 금지 - "투자하세요"가 아니라 "참고용"으로 표현
- [ ] 의료/법률 조언 금지 - "전문가에게 상담하세요" 문구 필수

## 6. 콘텐츠 / AI
- [ ] AI 답변임을 명시 ("AI가 생성한 답변입니다")
- [ ] 유명인 사주: 공개된 생년월일만 사용, 명예훼손 표현 금지
- [ ] 저작권: 토정비결 원문 복제 금지, 자체 해석 문구 사용
- [ ] LLM 사용 시 개인정보(실명/연락처)를 프롬프트에 넣지 않기

## 7. 보안 / 부정 방지
- [ ] 결제 금액 위변조 검증 (서버에서 orderId/amount 재조회)
- [ ] 코인 차감 트랜잭션 (동시 요청 중복 차감 방지 - DB row lock)
- [ ] Rate limit: 채팅/결제 남용 방지, CAPTCHA (결제 시)
- [ ] 로그 보관: 결제/코인/관리자 작업 5년

## 8. 세금 / 정산
- [ ] 매출/환불 장부, PG 정산 내역 대조 (월 1회)
- [ ] 부가세 신고 (코인 충전 시점 vs 사용 시점 - 세무사 확인)

## 변호사/세무사 상담이 꼭 필요한 부분
- 코인이 전자금융거래법상 선불전자지급수단에 해당하는지
- 환불 수수료율 (PG 실비 범위)
- 만 14세 미만 / 미성년자 결제 정책
